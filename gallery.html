Docs kit — gallery

Every component in ~/Docs/shared with a live example — a quick reference, and the page to re-check after changing the kit. The examples use one made-up system (a web shop's order service); nothing here describes a real one. The kit is English-only and generic: anything a single doc needs lives in that doc.

20doc-flow — a packet travelling hop by hop through a system

Sends the cart + session Checks the session Places the order orders + outbox order.created The request carries the shopper's session cookie. The gateway validates the session, then forwards with its own token. Work inside one node: from == to makes that node pulse. Order and outbox row in one transaction. A node placed by hand with at="row,col".

21doc-map — a real map with a camera tour (MapLibre + Turf)

A polygon is just a list of coordinates; the map fits the camera to it. Turf computes the bbox and its centre from the polygon — the drawing is the real math, not a hand-placed box. A fly view moves the camera (centre, zoom, pitch, bearing); pulsing markers draw the eye.

Illustrative shapes. Basemap: OpenFreeMap vector tiles (needs network; falls back to a plain background offline).

23doc-scrolly — scrollytelling: scroll the text, the visual follows

Checkout Places the order orders + outbox order.created Checkout. Saved in one transaction. The outbox relay publishes.

1 · The shopper pays

Each section drives the visual: data-go="#scrolly-flow:0" calls its go(0).

2 · One transaction

The order and its outbox row commit together, so an event is never lost or invented.

3 · The relay publishes

A separate process reads the outbox and publishes to Kafka. Works the same with doc-map, doc-steps and doc-seq.
